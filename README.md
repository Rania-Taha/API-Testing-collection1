# API Testing Project – Postman Collection

This project contains a Postman collection for testing REST APIs using CRUD operations.

## Features
- Add Book API
- Get Book By ID API
- Delete Book API
- Automated test scripts
- Status code validation
- Dynamic collection variables
- Collection Runner execution

---

## Tools Used
- Postman
- REST APIs
- JSON
- JavaScript
- GitHub

---

## Test Validations
- Verify response status code = 200
- Validate response messages
- Save generated book ID dynamically
- Run requests sequentially using Collection Runner
